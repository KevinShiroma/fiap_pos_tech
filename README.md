# 🤖 Pós-Graduação: IA PARA DEVS (FIAP + Alura)

Este repositório contém projetos, códigos e anotações desenvolvidas durante a Pós-Graduação **IA PARA DEVS** da **FIAP** em parceria com a **Alura**.

## 🎯 Objetivo do Curso

Proporcionar uma base sólida e abrangente das técnicas e habilidades essenciais para aplicar a **Inteligência Artificial** e o **Aprendizado de Máquina (Machine Learning)** em sistemas. O curso abrange desde conceitos fundamentais até a aplicação de **Modelos de Linguagem Avançados (LLMs)** e **IA Generativa (GenAI)**.

## 📚 Tópicos Principais

A matriz curricular aborda os seguintes temas centrais:

* **Fundamentos de IA e Machine Learning**
* **Machine Learning Avançado** (Modelos de Classificação, KNN, SVM, Kmeans)
* **Processamento de Linguagem Natural** (Tokenização, Stemming, Word Embeddings com Word2Vec)
* **Desenvolvimento de ML na Cloud** (AWS, Azure, Google Cloud)
* **LLMs** (Large Language Models) e a Era da Conversação Inteligente
* **IAs Generativas** (Geração de imagens e vídeos, desafios éticos)
* **Fine-Tuning** para Documentos
* **Análise de Mídia** (Vídeo, Áudio e Texto)

## 🛠️ Pré-Requisitos (Para Profissionais)

* Experiência profissional em desenvolvimento de software em pelo menos uma linguagem.
* Experiência em desenvolvimento Back-end ou Front-end, e em utilização de Banco de Dados SQL ou NoSQL.
